# 배포 오케스트레이터

2026-10-02 (금) 추가. **차기작 1화부터 적용합니다.**
끝난 50화 작품에는 거꾸로 적용하지 않습니다. 그 작품의 실적 데이터는 이 저장소에 없습니다.

AI 1분 숏드라마 한 회차를 분석해서 YouTube Shorts · TikTok · Instagram Reels ·
Facebook Reels · Threads · Naver Clip 에 **서로 다른** 배포 패키지를 만들고,
게시 전에 예측을 **잠근 뒤**, 게시 후 실적으로 판정하고, 그 결과를 학습기록으로 남겨
다음 회차와 다음 작품 제작에 다시 넣는 도구입니다.

## 어디서 여는가

| 어디서 | 주소 |
|---|---|
| 이 컴퓨터 | <http://127.0.0.1:8788/distribution> |
| 바깥 | <https://studio.saegimai.com/distribution> (만들기 콘솔과 같은 로그인) |

만들기 콘솔 왼쪽 띠의 **배포** 를 눌러도 됩니다. 공개 API(8787)로는 닿지 않습니다.

## 한 회차의 흐름

```
1 대본·영상 메모  →  2 패키지  →  3 예측 잠그기  →  (게시)  →  4 실적 2h·24h·72h·7d  →  5 리뷰  →  학습기록
                       ↑                                                                         │
                       └─────────────── 다음 회차 패키지 지시문에 자동으로 들어감 ─────────────────┘
```

1. **대본·영상 메모** — 모델은 영상을 직접 보지 못합니다. 첫 3초 화면, 컷, 자막처럼
   화면에서만 보이는 것은 영상 메모에 적어야 분석에 들어갑니다.
2. **패키지** — 분석 9항목 + 플랫폼 6곳 패키지 + 게시 전 예측이 한 번에 나옵니다.
   - `ANTHROPIC_API_KEY` 가 있으면 **패키지 만들기** 한 번.
   - 없으면 **지시문 복사** → Claude 에 붙여넣기 → 나온 JSON 을 **결과 붙여넣기**.
   - 해시태그 개수·빠진 플랫폼·플랫폼 간 같은 문구는 저장할 때 자동으로 검사해 노란 칸에 알려 줍니다.
3. **예측 잠그기** — 게시 **전에** 누릅니다. 잠그면 그 회차의 대본·패키지·예측은
   콘솔에서도, DB 에서 직접 해도 고쳐지지 않습니다 (SQLite 트리거가 막음).
4. **실적** — 시점(2h · 24h · 72h · 7d)을 골라 플랫폼별 숫자를 넣으면 바로 판정합니다.
   잠그지 않은 회차에는 실적을 넣을 수 없습니다.
5. **리뷰** — MISS 원인을 CONTENT · PACKAGING · DISTRIBUTION 으로 나누고,
   다음 화에서 바꿀 변수를 **최대 2개** 적습니다. 직접 적거나, Claude 리뷰를 받거나, 붙여넣습니다.

## 숫자 예측 규칙

모델은 조회수 숫자를 쓰지 않습니다. 플랫폼마다 "자기 최근 게시물 대비" 단계만 고릅니다.
숫자는 **잠그는 순간의 기준 데이터 중앙값 × 아래 배수**로만 계산합니다.

| 단계 | 배수 |
|---|---|
| 크게 밑돎 | 0.4 ~ 0.7 |
| 밑돎 | 0.6 ~ 0.95 |
| 비슷함 | 0.8 ~ 1.25 |
| 웃돎 | 1.1 ~ 1.8 |
| 크게 웃돎 | 1.5 ~ 3.0 |

- 기준 데이터는 **기준 데이터** 탭에서 플랫폼마다 최근 게시물 10개를 붙여넣습니다.
  칸 순서: `2h조회, 24h조회, 72h조회, 7d조회, 24h댓글` (모르는 칸은 `-`).
  스프레드시트에서 복사해도 되고 `1.2만`, `3천`, `1.5k` 도 읽습니다.
- 표본이 10개보다 적으면 범위 옆에 `*` (참고값) 이 붙습니다.
- 기준이 없는 플랫폼은 숫자를 내지 않고 "기준 없음"으로 둡니다.
- 2h · 72h · 7d 범위는 그 시점 칸을 채워 둔 플랫폼에만 생깁니다.

배수를 바꾸려면 `local-api/distribution/constants.mjs` 의 `OUTLOOK_MULTIPLIERS` 와 이 표를 함께 고칩니다.
이미 잠근 예측에는 영향이 없습니다.

## 판정 규칙

**플랫폼 하나 (조회수 기준)**

| 결과 | 판정 |
|---|---|
| 예측 범위 안 | HIT |
| 범위 밖이지만 가장자리에서 25% 안 | PARTIAL HIT |
| 그보다 더 벗어남 (밑돌든 웃돌든) | MISS |

**그 시점 전체**

- HIT = 1, PARTIAL HIT = 0.5, MISS = 0 으로 범위가 있는 플랫폼의 평균을 냅니다.
- 0.75 이상이고 "가장 강할 플랫폼" 예측이 틀리지 않았으면 **HIT**
  (0.75 이상이어도 그 예측이 틀렸으면 **PARTIAL HIT**)
- 0.4 이상 **PARTIAL HIT**, 그 아래 **MISS**
- 숫자 범위가 하나도 없으면 가장 강할·약할 플랫폼 예측 두 개로만 판정합니다.
- "가장 강했던 플랫폼"은 조회수 절대값이 아니라 **자기 기준 중앙값 대비 배수**로 고릅니다.
  기준이 없는 플랫폼을 강·약으로 예측했다면 그 예측은 채점하지 않습니다.

**MISS 원인 후보** — 실적 칸 오른쪽의 선택 지표를 **이전 회차들의 같은 시점 중앙값**과 견줍니다.

| 지표 | 이만큼 벗어나면 | 후보 |
|---|---|---|
| 노출(도달) 수 | 30% | DISTRIBUTION |
| 시청 시작률 | 15% | PACKAGING |
| 평균 시청 비율 · 완주율 | 15% | CONTENT |

후보는 결론이 아닙니다. 지표가 없거나 이전 회차가 없으면 "근거 없음"으로 나오고,
리뷰에서 근거가 지표인지 추정인지 구분해 적습니다.

## 학습기록

- 회차마다 판정이 나오면 `saegim.dist.learning/v1` 모양의 기록이 저장됩니다
  (첫 3초 사건, 쓴 제목, Threads 형식, 예측, 시점별 판정, 원인, 유지할 것, 다음 변경 ≤2).
- 다음 회차 패키지를 만들 때 **그 회차보다 앞선 기록만** 지시문에 자동으로 들어갑니다.
- **학습기록** 탭의 글을 복사하면 다음 작품 제작 프롬프트에 그대로 붙일 수 있습니다.
  집계(실측)와 다음 변경(제안)은 칸을 나눠 적습니다. JSON 으로도 내려받을 수 있습니다.
- 지난 50화 작품에서 확인된 교훈은 **작품 설정 → 이전 작품에서 넘겨받은 교훈** 에 직접 적습니다.
  확인된 것과 짐작을 구분해 적어 주십시오. 이 칸은 모든 회차 지시문에 들어갑니다.

## 회차 번호

- 작품 안에서 1화부터 매깁니다. 같은 번호는 만들 수 없습니다.
- 새 회차 칸에는 기존 기록을 확인한 **다음 번호**가 미리 채워지고, 결번이 있으면 알려 줍니다.

## 설정

`local-api/.env`

| 변수 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | 있으면 콘솔에서 바로 생성·리뷰. 없으면 붙여넣기 방식 |
| `DIST_MODEL` | 기본 `claude-opus-5-5` |

API 를 부를 때 거절이 나면 서버 쪽 대체 모델(`fallbacks: "default"`)이 이어받습니다.
local-api 는 외부 의존성을 두지 않는 원칙이라 SDK 대신 `fetch` 로 부릅니다.

## 파일

| 파일 | 무엇 |
|---|---|
| `local-api/distribution/prompt.mjs` | 오케스트레이터 지시문 · 출력 스키마 · 리뷰 지시문. 고치면 `PROMPT_VERSION` 을 올립니다 |
| `local-api/distribution/constants.mjs` | 플랫폼 · 시점 · 배수 · 허용 오차 등 숫자 규칙 |
| `local-api/distribution/forecast.mjs` | 기준 데이터 읽기 · 중앙값 · 숫자 범위 |
| `local-api/distribution/evaluate.mjs` | HIT / PARTIAL HIT / MISS 판정 · 원인 후보 |
| `local-api/distribution/learning.mjs` | 학습기록 · 제작 프롬프트 블록 |
| `local-api/distribution/store.mjs` | DB (`atelier.db` 의 `dist_*` 표) |
| `local-api/distribution/routes.mjs` | `/api/dist/*` |
| `local-api/distribution/claude.mjs` | Claude API 호출 |
| `local-api/studio/distribution.*` | 화면 |

## 시험

```bash
cd local-api
npm test
```

임시 DB 로 작품 만들기 → 잠금 → 잠긴 예측 수정 시도(막힘) → 실적 → 판정 → 리뷰 → 학습기록까지 돌려 봅니다.
