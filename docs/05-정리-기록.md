## 남은 두 가지

### 1. GitHub 저장소 `SoulMaru/saegimai-atelier`

작업 도중 만든 비공개 저장소입니다. 내용은 전부 이 저장소로 옮겨졌으므로 지워도 됩니다.
지우려다 **GitHub 2단계 인증 재확인**에 막혔습니다 (휴대폰 승인 또는 이메일 코드).

지우시려면:

1. <https://github.com/SoulMaru/saegimai-atelier/settings> 열기
2. 맨 아래 Danger Zone → **Delete this repository**
3. 2단계 인증을 마치고 저장소 이름을 그대로 입력

`gh` 로 하시려면 토큰에 권한을 더해야 합니다:

```bash
gh auth refresh -h github.com -s delete_repo
gh repo delete SoulMaru/saegimai-atelier --yes
```

### 2. `www.saegimai.com` 인증서

Vercel 대시보드에서는 **Valid Configuration** 이고 DNS 도 맞습니다
(`216.150.1.1`, 프록시 꺼짐). 다만 인증서가 아직 엣지에 깔리지 않아
접속하면 `SEC_E_WRONG_PRINCIPAL` (인증서 이름 불일치) 이 납니다.

Vercel 이 자동으로 발급합니다. 보통 몇 분, 늦으면 몇 시간 걸립니다.
`saegimai.com` 은 정상이므로 서비스에는 지장이 없습니다.

확인:

```bash
curl -sI https://www.saegimai.com/ | head -1
```

`HTTP/1.1 308` 이 나오면 끝난 것입니다.
