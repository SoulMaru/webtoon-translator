# 4단계 · 매일 쓰는 법

## 홈페이지 켜기 / 끄기

| 하고 싶은 것 | 하는 법 |
|---|---|
| 홈페이지 켜기 | `scripts\공방_열기.bat` 두 번 누르기 |
| 홈페이지 끄기 | 열린 창 두 개 닫기 |
| 지금 켜져 있나 확인 | <https://saegimai.com/status> 열기 |

껐을 때 방문자는 **"지금은 공방 문을 닫았습니다"** 안내 화면을 봅니다.
사이트가 깨진 것이 아니라 문을 닫은 것으로 보입니다.

## 새 작품 걸기

1. ComfyUI로 이미지를 만듭니다. (`ComfyUI_실행.bat`)
2. `scripts\새작품_등록.bat` 을 누릅니다.
   → `ComfyUI\output` 을 훑어 새 이미지를 찾아 등록합니다.
3. 등록 직후에는 **숨김** 상태입니다. 같은 창에서 이름을 붙이고 공개합니다:

   ```bash
   node admin.mjs list
   node admin.mjs title 4k-16x9-00002 "작품 이름"
   node admin.mjs desc  4k-16x9-00002 "한 줄 설명"
   node admin.mjs tags  4k-16x9-00002 "4K,가로"
   node admin.mjs show  4k-16x9-00002
   ```

홈페이지에는 30초 안에 반영됩니다.

## 작품 손보기

`local-api` 폴더에서:

| 하고 싶은 것 | 명령 |
|---|---|
| 목록 보기 | `node admin.mjs list` |
| 제목 바꾸기 | `node admin.mjs title <슬러그> "이름"` |
| 설명 바꾸기 | `node admin.mjs desc <슬러그> "설명"` |
| 태그 바꾸기 | `node admin.mjs tags <슬러그> 태그1,태그2` |
| 앞으로 당기기 | `node admin.mjs order <슬러그> 100` (숫자가 클수록 앞) |
| 잠깐 내리기 | `node admin.mjs hide <슬러그>` |
| 다시 걸기 | `node admin.mjs show <슬러그>` |
| 목록에서 지우기 | `node admin.mjs remove <슬러그>` |

## 화면 모양을 바꿨을 때

`web` 폴더의 코드를 고쳤다면 깃허브에 올려야 반영됩니다.

```bash
git add -A
git commit -m "화면 손질"
git push
```

Vercel이 알아서 다시 배포합니다.

## 어디가 무엇을 맡는가

```
방문자 ──▶ saegimai.com          Vercel  · 화면. 늘 켜져 있음
                 │
                 ├─ 켜짐 확인 ──▶ /health
                 └─ 작품·이미지 ▶ api.saegimai.com
                                     │  Cloudflare Tunnel
                                     ▼
                              내 PC :8787  · DB와 이미지 원본
                              (꺼지면 안내 화면)
```

- **작품 이미지와 DB는 깃허브에 올라가지 않습니다.** 내 PC에만 있습니다.
- Vercel은 이미지를 받아 크기를 줄여 캐시합니다. 12MB짜리 원본이 방문자에게 그대로 나가지 않습니다.

## 잘 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 늘 "문을 닫았습니다" | 로컬 API 창이 떠 있는지 → <http://127.0.0.1:8787/health> |
| 로컬은 되는데 사이트는 안 됨 | 터널 창이 떠 있는지 → <https://api.saegimai.com/health> |
| 사이트에 Vercel 로그인 화면 | [03-깃허브-버셀.md](03-깃허브-버셀.md) 3번 (Deployment Protection) |
| 이미지만 안 보임 | Vercel 환경변수 `NEXT_PUBLIC_ATELIER_API_BASE` 값 확인 |
| 커밋했는데 배포가 안 됨 | `git config user.email` 이 Vercel 계정 이메일과 같은지 |
