# 만들기 콘솔

2026-08-29 (토) 16:10 KST 완성.

ComfyUI 로 그림을 만들고, 마음에 들면 공개 갤러리에 거는 개인용 화면입니다.

## 어디서 여는가

| 어디서 | 주소 |
|---|---|
| 이 컴퓨터 | <http://127.0.0.1:8788> |
| 바깥 | <https://studio.saegimai.com> (로그인 필요) |

아이디와 비밀번호는 `local-api\.env` 의 `ATELIER_STUDIO_USER` ·
`ATELIER_STUDIO_PASSWORD` 입니다. 이 파일은 깃에 올라가지 않습니다.

## 공개 갤러리와 어떻게 갈라 두었는가

```
saegimai.com         → Vercel                     공개 갤러리 화면
api.saegimai.com     → 내 PC :8787                공개 · 작품과 이미지
studio.saegimai.com  → 내 PC :8788                개인 · 로그인해야 열림
                              ↓ 127.0.0.1
                        ComfyUI :8188             바깥에 열지 않음
```

**포트를 나눈 것이 핵심입니다.** 공개 주소인 `api.saegimai.com` 은 8787 만
보게 되어 있어, 콘솔에는 어떤 경로로도 닿을 수 없습니다.
실제로 `api.saegimai.com/api/state` 를 물어 404 를 확인했습니다.

ComfyUI 는 `127.0.0.1:8188` 로만 부릅니다. 터널에 올리지 않았습니다.

## 확인한 것

| 시험 | 결과 |
|---|---|
| `studio.saegimai.com` 인증 없이 | **401** |
| 틀린 비밀번호 | **401** |
| 올바른 자격증명 | 200 |
| `studio.saegimai.com/api/state` 인증 없이 | **401** (모든 경로가 막힘) |
| `api.saegimai.com` 으로 콘솔 접근 | **404** (닿지 않음) |
| 비밀번호 강도 | 32자 · 4종 · 약 210비트 |

## 실제로 걸리는 시간

이 컴퓨터(GTX 1660 Ti 6GB)에서 재 본 값입니다.

| 조건 | 첫 장 | 두 번째부터 |
|---|---|---|
| 기본 1.5 · 512px · 12단계 | — | **약 10초** |
| 리얼비전 XL · 1024px · 20단계 | 571초 | **약 106초** |

첫 장이 오래 걸리는 것은 모델을 디스크에서 읽기 때문입니다.
**ComfyUI 설정 문제가 아닙니다.**

> 한때 `--fp32-unet` 이 느림의 원인이라고 보았으나, 재 보니 그 옵션을
> 빼도 시간이 같았고 결과 파일의 체크섬까지 동일했습니다.
> `start-comfyui.ps1` 은 원래대로 두는 것이 맞습니다.
> 이 설정이 GTX 16-시리즈의 줄무늬 깨짐을 막아 줍니다.

## 쓰는 법

1. `scripts\공방_열기.bat` — 갤러리 API·콘솔·터널이 함께 뜹니다.
2. ComfyUI 는 따로 `ComfyUI_실행.bat` 으로 켭니다.
3. 콘솔에서 장면을 한 문장으로 적고 **만들기**.
4. 마음에 들면 이름·설명·태그를 적고 **갤러리에 걸기**.
   - `바로 공개 갤러리에 걸기` 를 끄면 보관만 하고 공개하지 않습니다.
   - 나중에 공개하려면 `node admin.mjs show <슬러그>`.

## 화면을 고치려면

| 파일 | 무엇 |
|---|---|
| `local-api/studio/studio.css` | 색·글꼴·배치 |
| `local-api/studio/index.html` | 뼈대 |
| `local-api/studio/studio.js` | 움직임 |

고친 뒤 **새로고침만** 하면 됩니다. 빌드도 배포도 필요 없습니다.
(공개 갤러리 쪽은 `src/app/(atelier)/` 이고, 그쪽은 git push 해야 반영됩니다.)

| 파일 | 무엇 |
