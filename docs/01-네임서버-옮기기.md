# 1단계 · 가비아에서 Cloudflare로 네임서버 옮기기

> **완료됨 — 2026-08-29 (토) 09:35 KST.**
> 결과는 [00-옮기기전-DNS기록.md](00-옮기기전-DNS기록.md) 에 있습니다.
> 아래는 나중에 되짚거나 다른 도메인에 같은 일을 할 때 보는 절차입니다.

도메인 **소유권은 계속 가비아**에 있습니다. DNS 관리만 Cloudflare로 넘깁니다.
Cloudflare Tunnel이 `api.saegimai.com` 을 자동으로 만들려면 이 과정이 먼저 있어야 합니다.

## 하는 일

1. <https://dash.cloudflare.com> 가입 후 로그인
2. **Add a site** → `saegimai.com` 입력
3. 요금제는 **Free** 선택
4. Cloudflare가 기존 DNS 기록을 훑어 보여 줍니다. 지금 쓰는 기록이 있으면 그대로 두고 **Continue**
5. 화면에 네임서버 두 개가 나옵니다.

> **이 계정에 이미 배정된 값 (2026-08-29 확인):**
>
> ```
> ignat.ns.cloudflare.com
> rihana.ns.cloudflare.com
> ```
>
> 1~5번은 이미 끝났습니다. 아래 "가비아에서 바꾸기"부터 하시면 됩니다.

## 가비아에서 바꾸기

1. <https://my.gabia.com> 로그인
2. **My가비아 → 서비스 관리 → 도메인**
3. `saegimai.com` 의 **관리** 버튼
4. **네임서버 설정**
5. 1차·2차 네임서버 자리에 위 두 줄을 넣고 저장

   | 자리 | 넣을 값 |
   |---|---|
   | 1차 | `ignat.ns.cloudflare.com` |
   | 2차 | `rihana.ns.cloudflare.com` |

   지울 것: `ns.gabia.co.kr` · `ns1.gabia.co.kr` · `ns.gabia.net`

> 가비아 기본 네임서버(`ns.gabia.co.kr` 등)를 지우고 Cloudflare 것으로 **바꾸는** 것입니다.
> 3차·4차 칸이 있으면 비워 두십시오.

## 확인

바뀌는 데 보통 10분~1시간, 늦으면 24시간까지 걸립니다.
Cloudflare 대시보드의 `saegimai.com` 상태가 **Active** 로 바뀌면 끝난 것입니다.

명령으로 확인하려면:

```bash
nslookup -type=ns saegimai.com
```

`ns.cloudflare.com` 이 나오면 넘어간 것입니다.
