# 3단계 · 깃허브에 올리고 Vercel에 붙이기

## 1. 깃허브 저장소 만들기

<https://github.com/new> 에서 만드십시오.

- 이름: `saegimai-atelier` (원하는 이름 아무거나)
- **Private** 로 두어도 Vercel은 잘 붙습니다.
- README·.gitignore·라이선스는 **추가하지 마십시오.** 이미 이 폴더에 있습니다.

그리고 이 폴더에서:

```bash
git remote add origin https://github.com/<계정>/saegimai-atelier.git
git push -u origin main
```

## 2. Vercel 프로젝트 만들기

1. <https://vercel.com/new> 에서 방금 만든 저장소를 고릅니다.
2. **Root Directory** 를 반드시 `web` 으로 지정하십시오.
   (저장소 뿌리에는 `local-api` 도 같이 있으므로, 그냥 두면 빌드가 안 됩니다.)
3. Framework Preset 은 **Next.js** 로 자동 잡힙니다.
4. **Environment Variables** 에 한 줄 넣습니다:

   | 이름 | 값 |
   |---|---|
   | `NEXT_PUBLIC_ATELIER_API_BASE` | `https://api.saegimai.com` |

5. **Deploy**

> **주의 — Hobby 요금제는 계정 소유자의 커밋만 배포합니다.**
> 다른 사람 이름으로 올라간 커밋은 배포가 `BLOCKED` 로 막힙니다.
> 커밋하는 git 이메일이 Vercel 계정 이메일과 같은지 확인하십시오:
> ```bash
> git config user.email
> ```

## 3. 로그인 없이 볼 수 있게 풀기 ★

**이 자리가 지난번 작업이 멈춘 곳입니다.** 대시보드에서만 됩니다.

1. Vercel 프로젝트 → **Settings**
2. 왼쪽 **Deployment Protection**
3. **Vercel Authentication** 을 **Disabled** 로
4. **Save**

이걸 안 풀면 방문자가 사이트 대신 Vercel 로그인 화면을 보게 됩니다.

## 4. 도메인 붙이기

1. Vercel 프로젝트 → **Settings → Domains**
2. `saegimai.com` 추가 → `www.saegimai.com` 도 추가
3. Vercel이 **넣어야 할 DNS 값을 화면에 보여 줍니다.** 그 값을 그대로 씁니다.
4. Cloudflare 대시보드 → `saegimai.com` → **DNS → Records** 에서 그 값을 넣습니다.

> **중요 — 프록시는 꺼 두십시오.**
> Cloudflare DNS 기록의 주황색 구름을 눌러 **회색(DNS only)** 으로 바꾸십시오.
> 켜 둔 채로 Vercel을 쓰면 인증서가 서로 물려 사이트가 안 열립니다.
>
> `api.saegimai.com`(터널)은 반대로 **주황색 구름이 켜져 있어야** 합니다. 그건 건드리지 마십시오.

## 5. 확인

- <https://saegimai.com> → 작품이 걸려 있으면 성공
- <https://saegimai.com/status> → `{"online":true}` 면 내 PC와 잘 이어진 것
