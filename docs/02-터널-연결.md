# 2단계 · 내 PC를 바깥으로 잇기 (Cloudflare Tunnel)

집 인터넷은 공인 IP가 고정이 아니고 공유기 뒤에 있습니다.
Vercel이 내 PC를 직접 찾아올 수 없으므로, 내 PC가 **먼저 Cloudflare 쪽으로 연결을 걸어 두는** 방식을 씁니다.
공유기 설정도, 포트 개방도 필요 없습니다.

`cloudflared` 는 이미 이 컴퓨터에 깔려 있습니다.

## 0. 먼저 — Cloudflare 계정 이메일 인증 ★

**인증 전에는 아래 1번이 반드시 실패합니다.**
2026-08-29 첫 시도에서 이 벽에 막혔습니다. 화면에는 아무 설명도 안 나오고
`권한 부여` 버튼만 반응 없이 멈춰 있는 것처럼 보입니다.
실제 API 응답을 까 보면 이렇습니다:

```json
{"success":false,"errors":[{"code":1211,"message":"Please verify your email."}]}
```

터널 자격증명은 Cloudflare API 토큰으로 만들어지는데,
이메일 미인증 계정은 토큰 발급 자체가 막혀 있습니다.

**할 일:** `okmceo@gmail.com` 받은편지함에서 Cloudflare 가입 인증 메일을 열어
확인 링크를 누르십시오. 그 뒤 1번부터 다시 하면 됩니다.

## 1. Cloudflare에 이 컴퓨터를 등록

PowerShell을 열고:

```powershell
cloudflared tunnel login
```

브라우저가 열립니다. `saegimai.com` 을 고르고 승인하십시오.

## 2. 터널 만들기

```powershell
cloudflared tunnel create atelier
```

이런 줄이 나옵니다:

```
Created tunnel atelier with id 1a2b3c4d-....
Tunnel credentials written to C:\Users\Microsoft\.cloudflared\1a2b3c4d-....json
```

**이 터널 ID를 적어 두십시오.**

## 3. api.saegimai.com 을 이 터널에 붙이기

```powershell
cloudflared tunnel route dns atelier api.saegimai.com
```

Cloudflare DNS에 기록이 자동으로 만들어집니다.

## 4. 설정 파일 넣기

`tunnel\config.example.yml` 을 `C:\Users\Microsoft\.cloudflared\config.yml` 로 복사하고,
`<터널ID>` 두 군데를 2번에서 적어 둔 값으로 바꾸십시오.

```yaml
tunnel: 1a2b3c4d-....
credentials-file: C:\Users\Microsoft\.cloudflared\1a2b3c4d-....json

ingress:
  - hostname: api.saegimai.com
    service: http://127.0.0.1:8787
  - service: http_status:404
```

## 5. 돌려 보기

먼저 로컬 API를 켜고(`scripts\start-local-api.ps1`), 다른 창에서:

```powershell
cloudflared tunnel --config "$env:USERPROFILE\.cloudflared\config.yml" run
```

그리고 브라우저에서 <https://api.saegimai.com/health> 를 여십시오.
`{"ok":true,...}` 가 보이면 성공입니다.

## 6. (권장) 컴퓨터 켜질 때 자동으로 뜨게

관리자 PowerShell에서:

```powershell
cloudflared service install
```

이렇게 하면 터널이 윈도 서비스로 돌아, 부팅할 때마다 알아서 붙습니다.
로컬 API는 `scripts\공방_열기.bat` 을 시작 프로그램에 넣어 두시면 됩니다.
