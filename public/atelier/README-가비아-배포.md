# saegimai.com 정적 홈페이지 배포 안내

## 패키지 개요

이 폴더는 원본 공개 페이지 `Atelier · 개인 이미지 작업실`의 화면, 스타일, 상호작용 스크립트 및 이미지 자료를 가비아 일반 웹호스팅에서 직접 서비스할 수 있게 정리한 **정적 배포 패키지**입니다. 원본 서비스 전용 분석·편집기 코드 및 원본 서비스 도메인을 향하는 이미지 참조는 제거했으며, 화면의 이미지 자료는 모두 `images/` 폴더에 포함했습니다.

| 항목 | 포함 여부 | 설명 |
|---|---:|---|
| 화면 레이아웃·스타일 | 포함 | 원본과 같은 Atelier 화면 구성 |
| 버튼·탭·입력 UI | 포함 | 브라우저 내 데모형 상호작용 |
| 이미지 자산 | 포함 | 로컬 `images/` 폴더에서 제공 |
| Google Fonts | 외부 사용 | Noto Sans KR, DM Sans, DM Serif Display |
| 실제 AI 이미지 생성 API | 미포함 | 별도 서버 또는 외부 API가 필요 |
| 서버 데이터베이스·로그인 | 미포함 | 가비아 일반 웹호스팅의 정적 파일 배포 범위 밖 |

## 업로드 방법

가비아 웹호스팅 관리 화면에서 제공하는 **웹FTP** 또는 FTP/SFTP 계정으로 접속한 뒤, 해당 계정의 공개 웹루트(일반적으로 `www`, `public_html`, `html` 중 하나로 표시됨)를 엽니다. 기존 운영 파일이 있다면 우선 백업한 뒤, 이 패키지의 `index.html`, `.htaccess`, `assets/`, `images/`를 **폴더 구조를 유지하여** 웹루트에 업로드하십시오. `verify-server.mjs`는 로컬 검증만을 위한 파일이므로 업로드하지 않아도 됩니다.

| 업로드 대상 | 필수 여부 | 목적 |
|---|---:|---|
| `index.html` | 필수 | 홈페이지 진입 파일 |
| `.htaccess` | 권장 | UTF-8·캐시·디렉터리 목록 설정 |
| `assets/` | 필수 | 화면 실행 스크립트 및 CSS |
| `images/` | 필수 | 로고, 본문 이미지, 공유 미리보기 |
| `README-가비아-배포.md` | 선택 | 운영 참고용 문서 |
| `verify-server.mjs` | 불필요 | 로컬 검증 도구이므로 업로드 제외 |

## 도메인과 SSL 전환

2026-08-28 기준으로 `saegimai.com`은 가비아 웹호스팅이 아니라 Cloudways 안내 페이지로 연결되어 있었습니다. 또한 HTTPS 연결은 인증서의 도메인 불일치 오류를 반환했습니다. 따라서 파일 업로드만으로는 홈페이지가 노출되지 않습니다. 가비아에서 발급한 웹호스팅의 IP 주소 또는 연결 정보를 확인한 뒤, 가비아 도메인 관리에서 `saegimai.com`의 A 레코드를 해당 IP로 변경하거나 가비아가 제시한 네임서버를 적용해야 합니다.

DNS 변경이 적용된 뒤에는 가비아 호스팅 관리에서 `saegimai.com`을 연결 도메인으로 등록하고 SSL 인증서를 발급·연결해야 합니다. 인증서가 정상 적용되기 전에는 HTTPS 강제 리디렉션을 설정하지 마십시오. DNS와 인증서의 전파·발급 시간은 서비스 설정에 따라 달라질 수 있습니다.

## 배포 후 점검

파일 업로드 및 도메인 연결 후에는 `http://saegimai.com`과 `https://saegimai.com`을 각각 열어 확인합니다. HTTPS에서 주소창의 보안 경고가 없어야 하며, 메인 이미지와 최근 작업 카드 이미지가 모두 표시되어야 합니다. 마지막으로 페이지에서 프롬프트 입력, 탭 전환, 비율 선택과 같은 브라우저 내 UI 상호작용이 작동하는지 확인합니다.

> 이 패키지는 **화면과 프런트엔드 데모 동작을 이전**합니다. 실제로 AI 이미지를 생성하고 작업 결과를 저장하려면 ComfyUI가 동작하는 별도 서버 또는 이미지 생성 API, 백엔드, 저장소 및 보안 설계가 추가로 필요합니다.

## 롤백 방법

문제가 발생하면 업로드 전 백업한 기존 웹루트 파일을 복원하고, DNS A 레코드를 기존 서버 IP로 되돌립니다. DNS 변경이 포함된 경우에는 캐시 및 전파 시간 때문에 복구가 즉시 모든 접속 환경에 반영되지 않을 수 있습니다.
